{#- Macros for the versioned Open mSupply documentation. Versions are declared in config.toml: [[extra.docs_versions]] label = "v2.21" # shown in the switcher section = "docs" # content path of the version's root section badge = "current" # optional, short, shown next to the label notice = "..." # optional HTML shown above every page of this version `current_section` is the content path of the version the current page lives in, worked out by `section_of` below. -#} {#- Works out which docs version a page or section belongs to and outputs its `section` path (e.g. "docs" or "docs/v3"), falling back to "docs". `candidates` is a list of section paths such as page.ancestors, or section.ancestors plus the section's own relative_path. The deepest one that matches a configured version wins, so nested versions (docs/v3 inside docs) resolve correctly for every language. Usage in a docs template: {% set_global current_section = macros_version::section_of(candidates=page.ancestors) %} -#} {%- macro section_of(candidates) -%} {%- set version_sections = config.extra.docs_versions | default(value=[]) | map(attribute="section") -%} {%- set_global found = "docs" -%} {%- for ancestor in candidates | reverse -%} {%- set ancestor_dir = ancestor | split(pat="/_index") | first -%} {%- if ancestor_dir in version_sections -%} {%- set_global found = ancestor_dir -%} {%- break -%} {%- endif -%} {%- endfor -%} {{- found -}} {%- endmacro -%} {#- The URL of the equivalent page in another version is the current path with the version section swapped. The page might not exist there; the 404 page lists the version roots. -#} {#- A compact {%- for v in versions %} {%- endfor %} {%- endif %} {% endmacro %} {#- A banner shown above the page content when the current version has a `notice` configured, with links to the same page in the other versions. -#} {% macro version_notice(current_section) %} {%- set versions = config.extra.docs_versions | default(value=[]) -%} {%- for v in versions %} {%- if v.section == current_section and v.notice %}
{{ v.notice | safe }} {%- set_global others = [] -%} {%- for other in versions %}{% if other.section != current_section %}{% set_global others = others | concat(with=other) %}{% endif %}{% endfor -%} {%- if others | length > 0 %} {%- for other in others -%} {{ other.label }}{% if other.badge %} ({{ other.badge }}){% endif %}{% if not loop.last %}, {% endif %} {%- endfor -%} {%- endif %}
{%- endif %} {%- endfor %} {% endmacro %}
