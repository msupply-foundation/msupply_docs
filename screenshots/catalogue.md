# Screenshot catalogue
Every image referenced from the English docs pages under `content/docs`, matched to the Open mSupply screen it was taken from and the region of that screen it shows.
Generated alongside [manifest.yaml](manifest.yaml) - see [README.md](README.md) for the region vocabulary and how the capture system is meant to consume this.

**734 distinct image files** referenced from 59 English pages (683 capturable from the demo server, 51 not). 138 carry hand-drawn annotations (arrows, circles, callouts) that a re-capture would have to reproduce.

Columns: **Region** is the part of the screen shown; **A** marks an annotated image; **Size** is the current pixel size of the committed file.
