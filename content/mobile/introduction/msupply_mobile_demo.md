<div class="warning">
Since October 2026, the mSupply Mobile demo server that was hosted on demo.msupply.org has been 
switched off. The mSupply Foundation has dicontinued the development of `mSupply Mobile` and our existing clients 
are required to upgrade to <a href="/docs/introduction/introduction"><strong>Open mSupply</strong></a>. 
</div>

Any new Android deployment of mSupply must now be done using Open mSupply.


# Request a Demo Store (Feature not supported)

![Custom invoices button on Navigator](/mobile/introduction/images/Request_a_Demo.png)

<div class="warning">
After starting mSupply mobile on the Android tablet, you will see a screen like the above for the first time. As mention above, the mSupply Mobile is no longer supported so the "Request a Demo Store" button to request credentials will no longer work.
</div>
